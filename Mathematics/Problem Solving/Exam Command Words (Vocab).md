# Exam Command Words 考试指令词

## Definition

A **command word** is the verb at the start of an exam question that tells you *how much working* to show and *what form* the answer must take. The command word is not decoration — it is the instruction. Mark schemes are written around it.

Matching the command word is as important as getting the right answer. A correct answer to "Prove" with no chain earns zero. A brief numerical check to "Verify" is worth full marks.

### 中文锚点 (Chinese Anchor)

中国学生常见的两种错配：

- **过度解释 (guòdù jiěshì)** — over-explaining. The question says "State the value of $k$." The student writes a paragraph. Wasted time; no extra marks.
- **过度省略 (guòdù shěnglüè)** — under-justifying. The question says "Explain why the function has no real roots." The student writes "discriminant $< 0$" with no sentence. Marks lost.

指令词 = 字面命令 + 隐含要求。(Command word = literal verb + implicit expectation.)

## Master Command Word Table

Official definitions from the Cambridge 0580 and 0606 syllabus (2025–2027). OxAQA 9260 does not publish a formal list, but the same conventions apply.

| Command word | 中文 | Official definition | Chain depth |
|-------------|------|---------------------|-------------|
| **Calculate** | 计算 | Work out from given facts, figures or information | Method + answer |
| **Construct** *(0580 only)* | 作图 | Make an accurate drawing | Drawing with visible arcs |
| **Describe** | 描述 | State the points of a topic / give characteristics and main features | Sentence(s); no calculation required |
| **Determine** | 确定 | Establish with certainty | Method + justified conclusion |
| **Explain** | 解释 | Set out purposes or reasons / make the relationships between things clear / say why and/or how and support with relevant evidence | Sentence giving the *reason* |
| **Give** | 给出 | Produce an answer from a given source or recall/memory | Bare answer |
| **Plot** | 画点 | Mark point(s) on a graph | Accurate pencil marks on grid |
| **Prove** | 证明 | (Not in 0580/0606 lists, but used) — rigorous logical argument from definitions | Every step justified |
| **Show (that)** | 证明 / 说明 | Provide structured evidence that leads to a given result | Every step visible, last line matches given |
| **Sketch** | 草图绘制 | Make a simple freehand drawing showing the key features | Shape + labelled features; not to scale |
| **State** | 陈述 | Express in clear terms | Bare answer; no working |
| **Verify** *(0606 only)* | 验证 | Confirm a given statement/result is true | Substitute and check |
| **Work out** | 算出 | Calculate from given facts, figures or information with or without the use of a calculator | Method + answer |
| **Write** | 写出 | Give an answer in a specific form | Answer in the requested form |
| **Write down** | 写下 | Give an answer without significant working | Bare answer |

> [!note] Where "Prove" fits
> Neither 0580 nor 0606 lists "Prove" as an official command word, but it appears in 9260 (Algebraic Proof, A8) and in A-Level. Treat "Prove" as a stricter "Show that" — every step must be airtight, and the final line must be the stated result.

## Contrast Pairs (Where Marks Are Lost)

### Sketch vs Plot

| Sketch 草图 | Plot 画点 |
|------------|-----------|
| Freehand curve, no grid needed | On graph paper, exact coordinates |
| Show **shape + key features** (roots, intercepts, turning points, asymptotes) | Show **exact position** of each point |
| Labels matter more than accuracy | Accuracy matters more than labels |
| Used for: curve families, transformations | Used for: data tables, experimental results |

Golden rule: *Sketch* rewards features; *Plot* rewards precision.

### State vs Describe vs Explain

| Command | What to write |
|---------|---------------|
| **State** | One-line answer. No justification. "State the period of $\sin x$." → "$360°$" |
| **Describe** | Two or three features. No reasoning required. "Describe the correlation." → "Strong, positive, linear." |
| **Explain** | Give the *reason*. A sentence beginning "Because…" or "Since…". "Explain why $x \geq 0$." → "Because $\sqrt{x}$ is only defined for non-negative $x$." |

Rule of thumb: **State = what. Describe = what in more detail. Explain = why.**

### Show (that) vs Prove vs Verify

| Command | Direction of argument | Chain requirement |
|---------|----------------------|-------------------|
| **Verify** | Start from the given answer; substitute it in. | Low — check one value. |
| **Show that** | Start from the given information; reach the stated result. | High — every step visible. |
| **Prove** | Start from definitions; reach the general statement. | Highest — no gaps, justify every inference. |

> [!warning] Never use the result in "Show that" or "Prove"
> "Verify" is the ONLY command that lets you substitute the answer into both sides. For "Show that" and "Prove", using the result is **circular reasoning** and earns zero. See [[Chain of Thought]] §5.

### Give vs Write down vs Write

All three mean "no working expected" — but with different flavours:

- **Give** — recall or read off. "Give the value of $5!$." → "$120$."
- **Write down** — answer from earlier working you already did. "Write down the gradient of the line." → "$3$."
- **Write** — answer in a *specific form* (e.g. standard form, simplest surd). "Write $\sqrt{50}$ in the form $a\sqrt{b}$." → "$5\sqrt{2}$."

If in doubt: show one line of working. Examiners rarely penalise *extra* working for these commands, but missing the required *form* for "Write" loses marks.

### Calculate vs Work out vs Determine

The three look identical but have subtle differences:

- **Calculate** / **Work out** — numerical answer, method visible. Practically interchangeable at IGCSE.
- **Determine** — same as calculate, but with an emphasis on *establishing* something (often involves a decision or comparison: "Determine whether $f$ is a function.").

Safe advice: show method for all three.

## Per-Curriculum Differences

### OxAQA 9260

9260 does **not** publish a formal command word list, but the AQA convention is used. Expect:

- "Show that" and "Hence" are frequent (especially in multi-part algebra questions).
- "Prove" appears in A8 Algebraic Proof — treat strictly.
- "Justify" = "Explain with evidence from your working." Similar to "Explain" but tied to a calculation you just did.
- Quality-of-written-communication (QWC) marks reward a clear chain of signal words (*therefore*, *since*, *hence*). See [[Chain of Thought]] §7.

### Cambridge 0580 Extended

- Full command word list in the syllabus front matter (p.64 of 2025–27 syllabus).
- Uniquely uses **"Construct"** — accurate drawing with compass and ruler, construction arcs visible. Not a synonym for "Sketch".
- No "Verify" in the official list (though it appears informally in some questions).

### Cambridge 0606

- Similar list to 0580, but **adds "Verify"** (confirm a given answer) and **drops "Construct"**.
- Heavier use of "Show that" and "Hence" — typically "Hence find…" or "Hence or otherwise solve…".
- "Hence" means *you must use the earlier result*. "Hence or otherwise" gives you a choice, but the earlier result is almost always the fastest path.

### A-Level (Cambridge 9709 — official list)

- 9709 publishes its **own command-word table** in the syllabus (2026–27, p.42), and it is short — eleven words: *Calculate, Describe, Determine, Evaluate, Explain, Identify, Justify, Show (that), Sketch, State, Verify*.
- The two worth drilling from that list: **"Determine"** = *establish with certainty* — full justification, not a plausible value; and **"Show (that)"** = *structured evidence leading to a given result* — the answer is handed to you, so every mark is in the chain.
- **"Verify"** is official at 9709 (= confirm a given statement/result is true — substitution suffices), unlike at 0580.
- Beyond the official list, papers freely use "Prove", "Hence", and "Deduce" — "Hence" means *use the earlier result*; "Deduce" likewise leans on what was just established. "Prove by induction" and "Prove by contradiction" are standalone skills.

## Common Misconceptions (Teaching Notes)

### 1. Over-explaining "State"

**Wrong:** For "State the modulus of $3 + 4i$", the student writes "$|3+4i| = \sqrt{3^2 + 4^2} = \sqrt{25} = 5$."

**Not wrong — but wasted effort.** "State" expects only "$5$". The marks are not higher for more working.

**Why it matters in exams:** 10 such over-explanations across Paper 4 = 5 minutes lost = 2 missed late-paper questions.

### 2. Under-justifying "Explain"

**Wrong:** For "Explain why $x$ cannot equal 2", the student writes "$x = 2$ doesn't work."

**Why it fails:** No *reason* given. "Explain" demands a because-clause: "Because the denominator $x - 2$ would be zero, which is undefined."

### 3. Treating "Show that" as "Verify"

**Wrong:** For "Show that $x = 3$ is a solution of $x^2 - 5x + 6 = 0$", the student substitutes $x = 3$ and writes "$9 - 15 + 6 = 0$. True."

**Why it can work here:** This one is a grey zone. Substitution *does* verify the root. For "Show that $x = 3$ is a solution", many mark schemes accept substitution. But for "Show that the solutions are $x = 2$ and $x = 3$", substitution alone does NOT show these are the *only* solutions — you must factorise or use the quadratic formula.

**Safe rule:** If "Show that" asks for a result that follows from a chain, build the chain. Substitution is only safe when the question literally says "Verify" or "Show that [this specific value] is a solution."

### 4. "Sketch" treated as "Plot"

**Wrong:** For "Sketch $y = x^2 - 4$", the student plots a dense table of values on graph paper.

**Why it's suboptimal:** "Sketch" does not need graph paper. Key features (roots at $\pm 2$, $y$-intercept at $-4$, minimum at $(0, -4)$, parabola opening upward) are what earn marks. See [[Sketching Curves (Vocab)]].

## Quick Reference Summary

| I see this command… | I should… |
|--------------------|-----------|
| State / Give / Write down | Write the answer. One line. |
| Write (in the form…) | Write the answer in the specified form. |
| Calculate / Work out | Show method, state answer with correct units. |
| Sketch | Freehand curve, label key features. |
| Plot | Accurate points on graph paper. |
| Construct *(0580)* | Use compass + ruler, leave construction arcs visible. |
| Describe | Two or three features, no "why" required. |
| Explain | Give a because-clause. |
| Show that | Build the chain to the given result. |
| Prove | Build an airtight chain from definitions. |
| Verify *(0606)* | Substitute the given answer and check. |
| Hence | Use the previous result; don't restart. |
| Hence or otherwise | Use the previous result (usually fastest). |
| Determine | Decide or find with justification. |
